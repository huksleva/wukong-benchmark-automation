Wukong Benchmark Automation 0.1.1 — Windows 10/11 x64

Download Wukong.Automation-win-x64.exe from GitHub Releases into a writable folder
and double-click it. This is ONE self-contained EXE: no ZIP extraction, .NET SDK,
Git or Visual Studio required. The first start extracts bundled dependencies into
Windows' per-user temporary cache automatically.

The setup wizard checks Steam, the FREE Black Myth: Wukong Benchmark Tool
(AppID 3132990), Windows OCR and local Tesseract. The full game is not required.
If Steam or the benchmark is missing, follow the installation prompt and retry.
Sign in to Steam and review first-launch agreements yourself. Complete the initial
shader compilation and first-launch dialogs once, then close the benchmark.
Before starting, the runner shows a warning and waits 5 seconds. Input is not locked.
During both tests, do not move the mouse, press keys, switch/minimize windows
or cover the benchmark. The runner brings it back to the foreground.
To cancel, focus the runner console and press Ctrl+C; wait for cleanup.
After interference, repeat the measurement without interacting with the computer.
A successful run restores the original INI, prints CPU/GPU FPS and report paths,
and attempts to open results/<run>/report.html using the Windows default app.
Chrome is not required. If no HTML app is available, the completed result remains
saved; read report.json in a text editor or open the HTML later in a browser.

Windows English OCR is required. Russian menus additionally require Russian OCR.
Tesseract and its model are bundled; native libraries need Microsoft Visual C++
Runtime x64 (2015–2022), normally installed by Steam. See the usage guide if a
check fails. This EXE does not include Steam, the benchmark or Windows OCR.
The EXE is not publisher-signed. Verify its source and SHA-256 before running.

PowerShell, in the EXE folder:
  .\Wukong.Automation-win-x64.exe doctor
  .\Wukong.Automation-win-x64.exe start
  .\Wukong.Automation-win-x64.exe --help

Linux/macOS: no automation executable. Existing HTML/JSON reports can be viewed
on either platform; the current Windows OCR and Win32 implementation is required
for running the tests. No Wine/Proton support is claimed.

Usage: https://github.com/huksleva/wukong-benchmark-automation/blob/main/docs/USAGE.md
Releases: https://github.com/huksleva/wukong-benchmark-automation/releases/latest
build-info.json identifies the source commit; SHA256SUMS.txt lists asset hashes.

Русский:
Скачайте Wukong.Automation-win-x64.exe из Releases и запустите двойным щелчком.
Это один файл; .NET и модель OCR включены. Мастер проверит Steam, бесплатный
Benchmark Tool и OCR. При отсутствии Steam или теста предложит открыть установку.
Вход в аккаунт, соглашения и первичная подготовка выполняются пользователем.
Затем программа сама проходит подсказку продолжения, выбирает настройки и
запускает оба теста. Не используйте мышь/клавиатуру во время проходов.
После успешного завершения откроется настоящий HTML-отчёт.
