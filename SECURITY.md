# Сообщение об уязвимости

Для этого репозитория используется [GitHub Private Vulnerability Reporting](https://github.com/huksleva/wukong-benchmark-automation/security/advisories/new). Сообщение получает владелец репозитория; оно не создаёт публичный Issue.

Опишите затронутый коммит, воспроизведение, возможное воздействие и минимальные данные для проверки. Не включайте действующие токены, пароли или чужие конфиденциальные файлы. Не публикуйте детали эксплуатации в Issues до обсуждения исправления.

## Область проекта

Сюда относятся обработка OCR/конфигурации, локальные файловые операции, формирование HTML и управление процессами утилиты. Проблемы Steam, Benchmark Tool и Windows направляйте разработчикам соответствующего продукта.

Проект экспериментальный. Для воспроизведения используйте актуальный `main`; отдельные поддерживаемые релизные ветки пока отсутствуют. Срок ответа и исправления не гарантирован.
