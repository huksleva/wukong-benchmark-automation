# Статус проверки

[← README](../README.md)

На 7 октября 2026 года проект находится на стадии проверки интеграции.

| Проверка | Состояние |
|---|---|
| Сборка Release | Выполнена локально |
| Автоматические проверки | 19/19: парсер, INI, конфигурация, HTML, стартовые экраны и обнаружение установки |
| Обнаружение установленного Benchmark Tool | Подтверждено командой `doctor`, Steam build `15365379` |
| Английский Windows OCR | Пройдена синтетическая проверка `doctor` |
| CPU/GPU/RAM через CIM | Подтверждено локально |
| Два реальных автоматических прохода | Ещё не подтверждены |
| FPS, настройки и восстановление после реального прохода | Ожидают полной проверки |

В первом интеграционном запуске возникли ошибки фокуса окна и ожидания завершения дочерних процессов. В повторном запуске восстановление INI и закрытие процессов прошли, но меню осталось на русском вопреки параметру `-culture=en`; затем потеря фокуса остановила сценарий. Успешные проходы ещё не зафиксированы. Установка инструмента и успешный `doctor` подтверждают предварительную готовность, а не выполнение бенчмарка.

GitHub Actions проверяет сборку и автоматические проверки на Windows. Steam и игру CI не запускает. Зелёный значок сборки не означает успешного прохождения реального CPU/GPU-сценария.

## Условия завершения интеграционной проверки

1. `run` завершается с кодом `0`.
2. `report.json` содержит `status: completed` и два прохода: `CPU` и `GPU`.
3. FPS совпадают с исходными экранами результатов, а настройки — с контрольными изображениями.
4. После закрытия инструмента исходные INI восстановлены побайтово.
5. Реальные результаты опубликованы отдельно от демонстрационных файлов.
