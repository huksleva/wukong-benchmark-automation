## Границы проверки

Проверен один компьютер с интегрированной AMD-графикой, один монитор и русский интерфейс. Другие видеокарты, английский интерфейс в полном сценарии, Windows 11, несколько мониторов и включённая RT в реальном проходе не проверены. Английский OCR проверен отдельно; наличие соответствующих подписей в адаптере не заменяет интеграционную проверку.

Трассировка на этом компьютере недоступна; GPU-проход использует Cinematic без RT. Сам Benchmark Tool предупреждает о низкой VRAM. Названия CPU/GPU отражают цель настроек: загрузка компонентов не измеряется, поэтому фактический ограничитель кадра не подтверждён. Диагностический OCR во время пролёта включён в условия замера.

При неизвестном меню или неприменённом обязательном значении программа останавливается с диагностикой и частичным отчётом. Универсальная работоспособность на любой сборке и любом компьютере не заявляется.

GitHub Actions проверяет сборку и автоматические проверки на Windows, создаёт готовый ZIP. Steam и Benchmark Tool в CI не запускаются; зелёный статус CI не является результатом игрового бенчмарка.
