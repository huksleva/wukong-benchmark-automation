# Профили и методика

[← README](../README.md)

| Настройка | CPU-проход | GPU-проход |
|---|---|---|
| Выходное разрешение | 1280 × 720 | Разрешение основного монитора |
| Графический пресет | Low | Cinematic |
| Дальность прорисовки | High | Cinematic, в составе пресета |
| Super Resolution Sampling | TSR | TSR |
| Масштаб внутреннего рендера | 50% | 100% |
| Full Ray Tracing | Off | On / Very High, если поддерживается |
| Frame Generation | Off | Off |
| VSync и ограничение FPS | Off | Off |

CPU-профиль снижает стоимость растеризации, освещения и обработки пикселей на GPU. Высокая дальность прорисовки сохраняет работу CPU по обработке сцены и подготовке команд. В GPU-профиле повышаются разрешение, качество эффектов и сложность освещения. При отсутствии поддержки трассировки используется Cinematic без RT; это явно отражается в отчёте. Генерация кадров отключена, чтобы результат не включал синтетические кадры. VSync и ограничение FPS отключены, чтобы не скрывать производительность компонентов.

**Названия профилей обозначают цель настроек, а не доказанное узкое место.** На слабой видеокарте даже CPU-профиль может оставаться ограничен GPU. На конкретном компьютере это следует проверить по загрузке GPU и изменению FPS при снижении внутреннего разрешения. Сам демонстрационный пролёт Benchmark Tool не является отдельным синтетическим тестом процессора и не моделирует все нагрузки полной игры.

## Метрики

Средний, минимальный и максимальный FPS берутся с итогового экрана Benchmark Tool. «95% FPS above» сохраняется, если однозначно распознан, и не является 1% low. Парсер проверяет `min ≤ average ≤ max`; оркестратор ждёт стабильного результата на нескольких кадрах.

## Подтверждение настроек

Запрошенные значения недостаточны для подтверждения прохода: утилита считывает значения из меню после применения и сохраняет контрольные изображения. Путь активного INI и подписи меню могут отличаться между сборками. Нераспознанное обязательное значение останавливает запуск. Проверка всей цепочки на настоящем инструменте пока не завершена; подробности в [VALIDATION.md](VALIDATION.md).
