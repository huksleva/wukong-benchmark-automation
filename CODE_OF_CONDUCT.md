# Правила общения

В Issues, Pull Requests и других обсуждениях проекта:

- Обсуждайте код и наблюдаемое поведение уважительно и по существу.
- Подкрепляйте замечания воспроизводимыми примерами; допускайте различия в опыте и оборудовании.
- Не допускаются оскорбления, травля, угрозы, дискриминация и публикация чужих личных данных.
- Не публикуйте пароли, токены и конфиденциальные журналы.

Владелец репозитория модерирует обсуждения и может скрывать сообщения или ограничивать участие при нарушении этих правил. Для сообщения о нарушении используйте доступный личный контакт владельца; чувствительные детали не размещайте публично.
