# Обработка локальных данных

[← README](README.md)

Утилита работает на локальном Windows-компьютере. OCR выполняется встроенным `Windows.Media.Ocr` и локальным Tesseract с включённой моделью; код проекта не отправляет изображения в облачный OCR и не загружает отчёты автоматически. Запуск Steam и Benchmark Tool может сопровождаться сетевыми запросами этих сторонних программ. Загрузка значков README также обращается к GitHub и Shields.io.

## Что сохраняется

| Данные | Где используются |
|---|---|
| CPU, GPU, RAM, ОС, архитектура, драйвер GPU | HTML/JSON-отчёт и вывод `doctor` |
| FPS и выбранные настройки | HTML/JSON-отчёт, OCR-данные и контрольные снимки |
| Видимая область окна Benchmark Tool | Итоговые и диагностические PNG; перекрывающие окна могут попасть в снимок |
| Пути установки, конфигурации и результатов | Журнал, конфигурация запуска, манифест резервной копии |
| Исходные и применённые INI | `backup/` и `effective-config/`; могут содержать идентификаторы и пользовательские параметры |

Результаты хранятся в папке `results/`. Она, `runner.local.json` и рабочие каталоги исключены из Git через `.gitignore`. Это не препятствует ручной загрузке файлов или принудительному `git add -f`.

## Публикация результатов

Публикуйте только нужные отчёты и изображения после просмотра содержимого. Уберите имена пользователей, личные пути, идентификаторы и наложения других окон. Не публикуйте весь `backup/`, `effective-config/` или локальную конфигурацию. После остановки всех процессов ненужную папку запуска можно удалить вручную.

Примеры в `docs/examples/` используют синтетические данные. Изображение вывода `doctor` содержит фактическую аппаратную конфигурацию и стандартные пути Steam, без имени пользователя.

Реальные опубликованные результаты находятся в `docs/results/2026-10-08/`: характеристики оборудования, FPS, настройки и изображения Benchmark Tool. Исходные INI, журналы с личными путями и локальная конфигурация не опубликованы. `provenance.json` содержит версию инструмента, исходный коммит и SHA-256 артефактов.

## Кэш автономного EXE

При первом запуске .NET извлекает встроенные библиотеки, OCR-модель и лицензии в пользовательский `%TEMP%/.net`. Это локальный кэш зависимостей; отчёты остаются в `results/` рабочей папки. Для запуска нужна доступная для записи временная папка.
